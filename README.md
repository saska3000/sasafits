# SasaFits

Дневник питания для двоих: калории, белки, жиры, углеводы. Работает в браузере и ставится на телефон как приложение.

Открыть: https://saska3000.github.io/sasafits/ (в Safari: «Поделиться» → «На экран "Домой"»).

## Как запустить на компьютере

В Терминале, в папке проекта:

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который покажет команда (обычно http://localhost:5173).

Чтобы открыть с телефона в той же Wi-Fi-сети, используйте адрес из строки `Network:` (например, http://192.168.1.5:5173). Камера для сканера так работать не будет — ей нужен HTTPS. Для проверки камеры в домашней сети: `npm run dev:https` и адрес `https://…:5443` (Safari предупредит о сертификате — это нормально).

## Как выложить новую версию

```bash
scripts/deploy.sh
```

Собирает приложение и отправляет его в ветку `gh-pages` — через минуту оно обновится на сайте.

## Что где лежит

- `src/screens` — экраны (дневник, добавление продукта, продукты, профиль)
- `src/components` — общие детали интерфейса
- `src/lib` — логика: база данных, расчёты, поиск
- `src/data/starterFoods.ts` — стартовая база продуктов (КБЖУ на 100 г)
- `src/data/menuRecipes.ts` — рецепты из нашего меню, `public/recipes` — их фото (авторы — в `src/data/photoCredits.ts`)
